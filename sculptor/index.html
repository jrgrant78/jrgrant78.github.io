How to Use Spatial Sculptor

Interface Toolbar Control Systems

Show / Hide
Toggles visibility layouts for console parameters and menus.
Grid Layer
Toggles visual projection for the space reference layout tracking matrix helper.
Reference
Superimposes the generated backdrop frame canvas at a distinct 75% opacity alignment depth profile completely behind structure points.
Scan Element
Captures current camera viewport dimensions to dispatch multi-pass asset interpretation processing pipelines via the Gemini cascade tree.
Gyroscope
Enables coordinate navigation using structural device motion data.
Clear / Reset
Purges all parsed asset architecture sub-elements from the scene matrix tree and resets camera parameters back to initialization defaults.

Navigation & Virtual Space Traversal

Orbit Look
Drag across the screen with one finger to rotate the workspace viewpoint perspective camera freely.
Pan Space
Drag across the screen with two fingers to translate camera positions laterally along the coordinate fields.
Zoom Focus
Pinch screen inward or outward with two fingers to adjust camera distance scaling vectors smoothly.

Touch Interaction Gestures

Single Tap
Selects an individual object element instance to highlight it and pull its real-world item description label directly into the console feed panel.
Double Tap
Triggers a temporary transparency material cohort for proximate meshes matching similar scale, orientation, and spatial clusters to resolve visibility clashing.
Long Press + Slide
Press and hold for 400ms to lift a complete isolated structure group entity into Translation Mode. Slide finger to reposition across full integer grid cells.
